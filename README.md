# Cafe Rosebean 랜딩 페이지

가상의 동네 카페 "카페 로즈빈"을 소개하는 간단한 정적 랜딩 페이지입니다.

## 이 폴더는?
이 폴더(`cafe-landing`)는 카페를 소개하는 한 장짜리 웹페이지를 담은 연습용 프로젝트입니다.
HTML과 CSS만으로 만들었고, 프레임워크나 빌드 도구, 외부 라이브러리는 쓰지 않습니다.

방문자가 페이지 하나에서 다음 내용을 차례로 볼 수 있습니다.
1. **히어로** — 카페 이름과 한 줄 소개, "메뉴 보기" 버튼
2. **우리의 이야기** — 스페셜티 원두, 매일 굽는 디저트, 편안한 공간
3. **대표 메뉴** — 커피와 디저트 6종과 가격
4. **오시는 길** — 주소, 영업시간, 연락처
5. **푸터** — 저작권 표기

## 구성
- `index.html` — 페이지 구조 (히어로, 소개, 대표 메뉴, 오시는 길, 푸터)
- `style.css` — 핑크·크림 톤 스타일, 모바일 반응형
- `README.md` — 이 설명 문서

## 실행 방법
별도 빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 참고
주소, 전화번호, 가격 등은 모두 예시 데이터입니다.
